# truecaso1
Esto es una prueba del servicio de GitHun.

## Cronómetro de consola

El repositorio incluye un pequeño cronómetro interactivo escrito en
Python. Para utilizarlo:

```bash
python cronometro.py
```

Una vez en ejecución puedes:

- Presionar **Enter** para registrar una vuelta.
- Escribir **p** para pausar o reanudar.
- Escribir **r** para reiniciar el conteo.
- Escribir **q** para terminar y ver el tiempo total junto con las
  vueltas registradas.
